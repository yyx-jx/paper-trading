## 修复记录

首次 30 客户端浸泡测试暴露出真实稳定性问题：

```text
现象：WS 批量断开重连，/api/health/ready 偶发 503。
主要错误：app-server PostgreSQL 连接进入 reconnecting。
影响：30 分钟在线测试未达成最终 30/30 在线。
```

已修复：

```text
1. pg idle client error 不再关闭整个 PostgreSQL pool。
2. 真正的 active query/write 失败仍按严格持久化策略处理。
3. WS heartbeat 从 1 次未响应即断开，调整为连续 3 次未响应才断开。
4. 生产运行参数调整：
   PG_MAX_CONNECTIONS=30
   PG_CONNECTION_TIMEOUT_MS=30000
   PG_IDLE_TIMEOUT_MS=60000
   MARKET_WS_MIN_INTERVAL_MS=250
MARKET_SNAPSHOT_INTERVAL_MS=250
   GAMMA_POLL_INTERVAL_MS=3000
```

远程部署说明：由于服务器当时无法拉取 Docker Hub `node:24-alpine` 元数据，本次修复采用先上传 `dist`、热补容器、`docker commit` 到 `app-app-server:latest` 和 `app-matching-service:latest`、再 `docker compose up -d --no-build --force-recreate` 的方式完成。后续网络恢复后，建议按标准 release build 重新构建一次镜像。
