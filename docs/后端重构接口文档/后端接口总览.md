# 后端接口总览

## 说明

本文档基于 `codex/deploy-backend-layering` 分支整理，用于后续前端重构和后端继续分层。文档不包含生产公网地址、真实账号、密码、token。

统一入口：

- HTTP API：`<API_BASE_URL>`
- WebSocket：由 `<API_BASE_URL>` 推导为 `ws://` 或 `wss://`
- 认证：除健康检查、登录和 Prometheus metrics 之外，业务接口使用 `Authorization: Bearer <TOKEN>`

## 健康与监控

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/health` | 服务基础健康、持久化、行情源、撮合服务概要 |
| GET | `/api/health/live` | 存活检查 |
| GET | `/api/health/ready` | 就绪检查，包含数据库、迁移、行情源和撮合服务状态 |
| GET | `/api/metrics` | JSON 运行指标 |
| GET | `/metrics` | Prometheus 文本指标，按配置启用并受 Basic Auth 保护 |

## 认证与当前用户

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/auth/login` | 无 | 登录，返回 token 和用户基础信息 |
| POST | `/api/ws/tickets` | 登录 | 申请一次性 WS ticket |
| GET | `/api/me` | 登录 | 当前用户信息 |
| GET | `/api/bootstrap/full` | `trade:view`、`profile:view` | 登录后完整初始化快照 |
| POST | `/api/me/language` | 登录 | 修改语言 |
| PATCH | `/api/me` | 登录 | 修改个人资料 |
| POST | `/api/me/password` | 登录 | 修改密码 |

## 用户管理

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/users` | `users:list` 或可管理范围 | 用户列表 |
| POST | `/api/users` | `users:create` | 创建单个用户 |
| PATCH | `/api/users/:id` | 管理权限 | 更新用户资料、角色、权限等级、余额等 |
| GET | `/api/users/bulk/template.csv` | `users:bulk-create` | 下载批量创建 CSV 模板 |
| POST | `/api/users/bulk/csv/preview` | `users:bulk-create` | CSV 预览 |
| POST | `/api/users/bulk/csv` | `users:bulk-create` | CSV 批量创建 |
| POST | `/api/users/bulk` | `users:bulk-create` | JSON 批量创建 |
| POST | `/api/users/:id/disable` | 管理权限 | 禁用用户 |
| POST | `/api/users/:id/enable` | 管理权限 | 启用用户 |
| POST | `/api/users/:id/reset-password` | 管理权限 | 重置密码 |
| POST | `/api/users/:id/balance` | 管理权限 | 设置模拟可用余额 |

| --- | --- | --- | --- |
| GET | `/api/rounds/current` | `trade:view` | 当前轮次和市场快照 |

| POST | `/api/rounds/:id/manual-settlement` | 非 Tester | 手动结算 |

| GET | `/api/profile/me` | `profile:view` | 账户资产概览 |
| GET | `/api/positions/me` | `profile:view` | 当前用户持仓 |
| GET | `/api/orders/me` | `profile:view` | 当前用户订单 |
| POST | `/api/orders` | `trade:order:create` | 下单 |
| POST | `/api/orders/:id/cancel` | `trade:order:cancel` | 撤单 |
| POST | `/api/positions/:id/sell` | `trade:position:sell` | 卖出单个持仓 |
| POST | `/api/positions/close-side` | 交易权限 | 按方向平仓 |
| POST | `/api/positions/reverse-side` | 交易权限 | 反手 |
