## 客户端代理兼容

2026-05-09 排查到 Windows 客户端在本机启用系统代理 `127.0.0.1:7897` 时会显示“后端离线”：服务端健康检查正常，但客户端请求被系统代理转发后超时。已处理：

```text
本机临时修复：Windows 代理绕过列表加入 103.147.13.98 和 103.147.13.98:10001。
打包修复：生产客户端打包时写入 productionApiBaseUrl 元数据。
运行时修复：Electron 启动时自动把生产 API 主机加入 proxy-bypass-list。
```

后续重新分发客户端时，应使用修复后的安装包。用户本机即使开启系统代理，也应直连 `103.147.13.98:10001`。
