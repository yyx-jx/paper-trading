## Key Changes

- 交易分析页数据源改为逐笔买入记录：
  - 不再用已关闭仓位的 `notionalSpent` 作为原始投入。
  - 买入总花费用买入时记录的原始总成本。
  - 买入成本价显示纯成交均价；费用单独显示。
  - 卖出/结算价格显示退出成交价或结算价。
  - PNL 按 `退出/结算所得 - 买入总成本 - 退出费用` 展示。
- 时间展示：
  - 分析页时间列改为 `YYYY-MM-DD HH:mm:ss UTC`。
  - 轮次/记录标签中的 `B5` 改为 `HT`，并补全年月日。
  - 保留现有“全部/年/月/周/日/交易”快捷筛选，不新增日期范围输入。
- 当前问题根因：
  - 投入为 0 但有 PNL，是因为卖出/结算后仓位剩余成本被清零，而分析页错误地拿它当原始投入。
  - 入场价小数是官方成交价/均价允许小数；当前 `averageEntry` 还混入了费用成本口径。
